# Threadgarden

## The to-do list

The owner's to-do list for this project is an Obsidian vault in the private repo
`JiriPlasek/obsidian-vault`. The notes are under `Threadgarden/`: the hub
`Threadgarden.md` with its "Now" list, plus one note per area (Remote machines,
Power, Phone, Releases, To decide, Bugs and polish).

- **On a new machine,** clone it (usually to `~/Documents/MyShit`) and open that
  folder as the vault in Obsidian.
- **Before reading it,** `git pull` so it's current.
- **Keep it up to date.** When something is finished, decided or deferred, update
  the matching note, then commit and push.
- `Threadgarden/Dev notes.md` holds passwords and stays out of git (it's in the
  vault's `.gitignore`). Never add it, and never copy anything from it elsewhere.
