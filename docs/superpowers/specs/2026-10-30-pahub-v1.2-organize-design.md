# pahub v1.2 — Organizing chats: recency groups, buckets, missing folders

**Date:** 2026-10-30
**Status:** Approved by owner (in conversation) for implementation
**Builds on:** [v1 design](2026-10-30-pahub-v1-design.md) and [v1.1](2026-10-30-pahub-v1.1-activity-design.md). The v1 anti-goals still outrank everything: never slow, never damage Claude Code's data, never fall behind Claude Code, never crash or lose work.

## 1. Why

With hundreds of chats across dozens of projects, a flat list stops working. The owner asked for:

1. Chats grouped by recency.
2. A better way to deal with the many `pahub-real-*` projects (leftovers of pahub's own real-Claude test runs, whose temporary folders were deleted; Claude Code keeps their transcripts).
3. Larger buckets to sort threads into: Active, On hold, Archived.

## 2. Recency groups

The chat list of every place is split into sections with sticky headers:

- **Needs you** and **Running** chats first (as today; they are the "now" section).
- **Last 24 hours**, **Last 7 days**, **Last 30 days**, **Older** — by last activity.
- Empty sections are not shown. Section headers show a count. Keyboard navigation (↑/↓) moves across sections seamlessly; the virtual list keeps its performance budget with headers as rows.

## 3. Buckets: Active, On hold, Archived

Every chat has exactly one **state**: `active` (default), `onHold`, or `archived`. The state is pahub's own metadata (stored in `pahub.db`), never written into Claude Code's data.

**Places (left column):** ◐ Needs you · ● Running · **Active** (replaces "All chats") · **On hold** · **Archived**, each with a count. Selecting a project shows that project's Active chats, with a small toggle in the list header to include on-hold and archived chats.

**On hold:**
- Optional **until**: Tomorrow (09:00 local), Next week (Monday 09:00), or a picked date/time; optional short **note** ("waiting for review from Petr").
- When `until` passes, the chat returns to Active and appears under Needs you as **"Back from hold"** (its own indicator), with a desktop notification (respects the notification setting). Opening it clears the indicator.
- The note and the until-date are shown in the row and the chat header.

**Archived:**
- Hidden from Active, project lists, the running-agents strip and the Ctrl+K main results (Ctrl+K lists archived matches in a separate group at the end).
- **Auto-unarchive:** an archived chat returns to Active when it starts running again (e.g. resumed from a terminal, or appears as a running external session) or when the user sends it a message — nothing gets lost in the archive.
- Archiving a chat that pahub is running asks to end it first (confirmation), then archives.

**Changing state:**
- Chat row context menu and a chat header menu: Make active / Put on hold… / Archive.
- Keyboard, when the chat list has focus: **E** archive, **H** put on hold (opens the until/note popover), **A** make active. Added to the shortcuts panel and README.
- **Multi-select** in the chat list (Ctrl/Cmd+click toggles, Shift+click ranges, Ctrl/Cmd+A selects the visible section) with a bulk action bar: Make active / Put on hold… / Archive.
- **Tidy action:** the **Older** section header offers "Archive all older than 30 days" (confirmation shows the count; live chats are skipped).

**Needs you** precedence is unchanged: a chat waiting on the user shows under Needs you even when on hold or archived (it is auto-unarchived when it starts running).

## 4. Missing folders

Projects whose folder no longer exists (v1.1 §4 groups them into a collapsed **Missing folders** section) get:

- A **"Hide all missing"** action on the section header (confirmation; uses the existing per-project hide, so it is reversible from the hidden-projects section).
- A tooltip on the section explaining why they appear ("Claude Code still has these chats, but their folders were deleted").

## 5. Out of scope

Custom user-defined buckets or tags; automatic archiving without confirmation; syncing states across machines.
